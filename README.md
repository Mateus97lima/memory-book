# 📸 Memory Book

O **Memory Book** é uma aplicação web desenvolvida para guardar e visualizar momentos especiais através de fotos. A proposta é proporcionar uma experiência simples e agradável para organizar memórias em um formato visual inspirado em um álbum de fotos.

## 🚀 Tecnologias utilizadas

* **JavaScript**
* **TypeScript**
* **React**
* **Vite**
* **Tailwind CSS**
* **HTML5**
* **CSS3**

## ✨ Funcionalidades

* 📖 Visualização das memórias em formato de álbum
* 📸 Adição de fotos pelo usuário
* 🖼️ Exibição das fotos adicionadas
* 🗑️ Possibilidade de excluir memórias.
* 📅 Organização das memórias por data.
* ❤️ Possibilidade de favoritar memórias.
* ✏️ Possibilidade de editar informações das memórias.
* 🎨 Interface moderna e responsiva
* ✨ Animações e interações para melhorar a experiência do usuário
* 🧩 Componentização utilizando React
* 🎨 Estilização utilizando Tailwind CSS

## 🔮 Melhorias futuras

O projeto ainda está em desenvolvimento e algumas funcionalidades estão planejadas para as próximas versões:

* 🗄️ **Integração com banco de dados** para armazenar as informações e fotos.
* 🔐 **Sistema de login e autenticação**, permitindo que cada usuário tenha sua própria conta.
* 👤 **Área personalizada do usuário**, mostrando as fotos e memórias associadas à sua conta após o login.
* ☁️ **Armazenamento persistente das imagens**, permitindo que as fotos continuem disponíveis mesmo após sair da aplicação.

## 🎯 Objetivo do projeto

O projeto foi desenvolvido para colocar em prática conhecimentos de **React, TypeScript, JavaScript, Vite e Tailwind CSS**, além de explorar conceitos de componentização, organização de código, estilização e experiência do usuário.

O objetivo é continuar evoluindo o **Memory Book**, adicionando autenticação, banco de dados e armazenamento persistente para transformar o projeto em uma aplicação completa de gerenciamento de memórias pessoais.

## 🛠️ Como executar o projeto

Clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Entre na pasta:

```bash
cd memory-book
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Depois, acesse a URL exibida pelo Vite no terminal.
